================================================================================

[ENGLISH]
Welcome! You can easily translate RetroChat into ANY language using this guide.
RetroChat automatically scans this folder (.minecraft/config/retrochat/lang/)
for any ".json" files. When you add a new file here, it will immediately appear
in the in-game RetroChat Settings!

--------------------------------------------------------------------------------
STEP 1: Copy the English JSON template below.
STEP 2: Translate the values into your target language.
STEP 3: Save the translated content as a JSON file in this folder:
        .minecraft/config/retrochat/lang/<language_code>.json
        (Example: fr_fr.json for French, es_es.json for Spanish, ru_ru.json for Russian)
STEP 4: Launch Minecraft! Your language will be detected automatically or selectable
        in the RetroChat Settings menu!
--------------------------------------------------------------------------------

================================================================================
[TÜRKÇE] YENİ DİL NASIL EKLENİR?
================================================================================
1. Yukarıdaki İngilizce JSON şablonunu kopyalayın.
2. Değerleri hedef dilinize çevirin.
3. Yeni bir metin dosyası açıp içine yapıştırın ve dosya adını <dil_kodu>.json
   olarak bu klasöre kaydedin (.minecraft/config/retrochat/lang/fr_fr.json).
4. Oyunu açtığınızda yeni dil otomatik olarak listeye eklenecek ve RetroChat
   Ayarlar menüsünden seçilebilir olacaktır!
